# Rock Paper Scissors GUI Game

Description:
This project is a Rock Paper Scissors game built with Python. The user plays against the computer by clicking Rock, Paper, or Scissor buttons. The program randomly chooses the computer’s move and keeps track of both scores.

Language Used:
Python

Libraries Used:
Tkinter
Random

Features:
- GUI game window
- Rock, Paper, and Scissor buttons
- Random computer choice
- Score tracking
- Shows user choice and computer choice
